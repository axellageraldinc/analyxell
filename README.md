# daignostic

AI-assisted game performance diagnostics for Windows.

daignostic reads [CapFrameX](https://github.com/CXWorld/CapFrameX) captures, charts them,
compares runs, and explains likely causes of stutter and low frame rates.

> Status: early development. Nothing here is released yet.

Full documentation (guide, ADRs, BDRs, contributing) is being written.
